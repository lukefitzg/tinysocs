# TS-130 — Account Discovery

> Account enumeration commands (net user, net localgroup, whoami /all)

## What it detects

Event ID `4688` on channel `Security`, grouped by
`winlog.event_data.SubjectUserName`, firing at threshold `5` within a
`5`-minute window.

Only counts events whose `winlog.event_data.NewProcessName` contains one of: `net.exe`, `net1.exe`, `whoami.exe`, `nltest.exe`, `dsquery.exe`, `quser.exe`….

# TS-082 — Amsi Bypass

> AMSI bypass patterns in ScriptBlock (4104)

## What it detects

Event ID `4104` on channel `Microsoft-Windows-PowerShell/Operational`, grouped by
`winlog.computer_name`, firing at threshold `1` within a
`5`-minute window.

Only counts events whose `winlog.event_data.ScriptBlockText` contains one of: `AmsiUtils`, `amsiInitFailed`, `AmsiScanBuffer`, `SetValue(null`.

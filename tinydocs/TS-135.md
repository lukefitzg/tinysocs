# TS-135 — Lolbin Proxy Execution

> LOLBin proxy execution (rundll32, mshta, regsvr32) detected via process creation

## What it detects

Event ID `4688` on channel `Security`, grouped by
`winlog.event_data.NewProcessName`, firing at threshold `3` within a
`5`-minute window.

Only counts events whose `winlog.event_data.NewProcessName` contains one of: `rundll32.exe`, `regsvr32.exe`, `mshta.exe`, `wmic.exe`, `certutil.exe`.

# TS-132 — Ingress Tool Transfer

> File download via certutil, bitsadmin, or PowerShell (process creation)

## What it detects

Event ID `4688` on channel `Security`, grouped by
`winlog.event_data.NewProcessName`, firing at threshold `2` within a
`5`-minute window.

Only counts events whose `winlog.event_data.NewProcessName` contains one of: `certutil.exe`, `bitsadmin.exe`.

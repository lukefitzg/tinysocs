TinySocs

A tiny, self-hosted SIEM for small Windows networks. One installer stands up event collection, a detection engine, a bundled OpenSearch backend, and a web dashboard — on your own hardware. Your data stays on-prem.

Built for homelabs, tinkerers, students, and small IT shops. Free to use. No account, no waitlist, no tiers.

Download the installer Source on GitHub

What you get

  • Windows agent (C#) collecting Security, Sysmon, and Defender events
  • 19 detection rules enabled out of the box (39 defined — the rest are off by default and yours to enable), covering 16 MITRE ATT&CK techniques across 8 tactics
  • Rules are plain YAML, hot-reloaded — edit them, tune them, write your own
  • Dashboard with alerts, fleet health, event explorer, and an optional AI assistant (Claude, OpenAI, or fully-local Ollama)
  • File integrity monitoring, threat-intel enrichment, Slack/Teams/email alerts
  • NIST CSF / HIPAA / PCI DSS coverage-mapping reports
The honest fine print. This is a solo side project, provided as-is with no support — there's a support policy, a known-limitations doc, and good self-diagnostics, but no SLA and no promised release cadence. Detection validation evidence — including the misses — lives in the repo, not in marketing claims. Windows-only; ~100 endpoints per node.

Quick start

Download TinySocs-Setup.exe, run as Administrator, pick the Hub role, follow the wizard. Verify with Test-TinySocsHealth. The getting-started guide covers it end to end.
